# 第１弾（段階B〜D）の搭載部品と重量

調査・選定日：2026-11-16。購入前の設計版。

第１弾は、元の段階計画でいう**段階D完了の初号機**とする。目標は飛行・FPV映像・下向き測距・プログラム制御。段階Bの制御機器、段階Cの機体と映像、段階Dの距離センサーを搭載する。プログラムはPixhawk上のArduPilot・Lua・保存ミッションを使う計画で、機上PCは追加しない。

段階Eの散布ポンプ・ノズル・配管・水、段階FのF9P・RTK補正無線・変換MCUは含めない。GPSはM10を使う。今回はタンク本体も非搭載とし、フレームの脚・支持構造は残す。

元資料：ローカルの `drone_phased_build_plan.xlsx`「段階計画」B4・A13:H17、「部品予算」B8:K22、「設計・検証」A8:C20。Excel本体は変更・公開していない。

**この設計案の重量集計は約12.34kg（電池込み、水・散布装置・RTKなし）。** 未公表重量には明示した仮割当を使っており、完成実測値でも上限でもない。G06の正味重量・トレー適合、G12セットの同梱版、電池端子の電流条件は未解決で、発注・組立にそのまま使える完全確定BOMではない。

## 今回選定したもの

- 電源分配と補助電源：**MATEKSYS FCHUB-12S V2**。PM08はFC給電とDroneCAN電流・電圧測定に使い、FCHUBは推進系の分配と補助機器用5.1V・12V電源に使う。
- 無線・映像：**日本版G12セット、GR01受信機、Skydroid 3-in-1 Ethernet/LANカメラ**を見積・調達時の指定構成とする。国内セットの同梱型番との一致は公開ページだけで確認できなかったため、条件付き選定。
- 記録媒体：**Transcend High Endurance TS32GUSD350V 32GB**。
- 電池固定：予定の6S 10Ah電池2本に合わせた追加トレー・固定部材を選定。G06純正収納部への適合が確認できていないため、追加トレーは寸法・材料を定めた設計案であり、取付検証は未実施。

詳細は[電源・配線](power-selection.md)、[制御機器・無線・映像](avionics-selection.md)、[フレーム・固定部材](structure-selection.md)に分けている。

## 重量の読み方

重量は実測値ではない。**公表値、包含範囲に条件がある公表値、材料からの計算値、設計上の仮割当**を区別する。公開されていない重量を0gとは扱わない。仮割当はメーカー重量でも保証上限でもない。

特にG06の5.4kgは、脚・タンク等の包含範囲が確定していない。この表では5.4kgを暫定計上し、タンクを外すからといって750gを差し引かない。正味フレーム重量が判明したら、その行を置き換える。

### 重量の合計と限界

| 集計 | 重量 |
| --- | ---: |
| 主要部品の条件付き公表値部分小計 | 11,341.0g |
| 追加機器・配線・取付材 | 997.7g |
| **設計案の搭載重量** | **12,338.7g ≒ 12.34kg** |

全体の根拠別内訳は、公表値を使った行11,351.8g、材料計算491.9g、仮割当495.0g。公表値にもフレームの包含範囲や付属品の扱いという条件が残る。小数は集計の追跡用であり、機体重量を0.1g単位で予測できるという意味ではない。

電池だけでも2本合計±30gの掲載公差があり、仮割当やフレーム仕様の差はこれとは別である。未確定部品が全て枠内に収まる保証はない。元計画の「完成形の空荷11.9kg以下」は、この第１弾の集計で達成したとは言えない。段階E・Fでの追加・交換を含めた重量は、別の構成表で再計算する。

## 第１弾とSITLの関係

[実験002](../../sitl/experiments/002-g06-payload/README.md)の空荷13.4946kgは、完成形の部品群を想定した仮の荷重条件である。水0Lケースも、このB〜Dの部品表を積み上げた機体ではない。実験002の条件・結果はそのまま履歴として残す。

[実験003](../../sitl/experiments/003-prototype-bd/README.md)では、この部品表の12.3387kgと仮の部品配置から重心・慣性を設定し、基本飛行・AUTO航路・下向き測距と重量感度を試験した。11/11回で記録した判定条件を満たした。FPV・G12無線・Remote ID・電源配線は主に重量としての反映であり、全機器の実機動作や取付適合が確認できたことにはならない。
