# 第１弾の制御・通信・センサー選定

調査日：2026-11-16。対象は段階B〜Dの初号機（飛行、カメラ、下向き測距、プログラム制御）。本書は購入仕様と重量集計の根拠を決める資料であり、実機での接続試験結果ではない。

## G12の購入指定と残る確認

[国内販売ページ][A3]には日本版・FPVカメラ付きと記載されているが、同梱受信機とカメラの型番、機上アンテナの型式・本数は公開されていない。したがって「国内セットを注文すればGR01と指定カメラが届く」とはまだ断定できない。

購入仕様は次の内容で指定する。現時点で販売店への連絡・注文は実施していない。

- G12日本版の送信機、GR01受信機、それに対応する日本版セットの指定アンテナ・フィーダー一式。
- 3-in-1 Cameraの**Ethernet/LAN版**、12〜72V対応仕様、受信機へ接続する専用LANケーブルとカメラ電源ケーブル。
- GR01用XT30電源リード、SBUS・UART接続用リード。付属しない場合は追加品として数量・ピン配列を確定する。
- 納入される送受信機・アンテナの組合せ、日本版の設定、Pixhawk 6CとのSBUS/MAVLink接続方法を販売店の回答で確認する。

メーカーのG12取扱説明書にはGR01とG12 RXの両方が掲載されている。**GR01は37g・7.2〜72V・XT30入力、G12 RXは45g・5V入力**なので、見た目が似ていても置き換えない。GR01にはSBUS、UARTデータ伝送、LANの各インターフェースがある。[A4]

国内セットと指定構成の一致が確認できなければ、この行は「条件付き」のままとする。海外版の受信機やアンテナを無断で混ぜて確定扱いにはしない。

G12の公式取扱説明書の冊子42ページには、QGroundControlで表示するRTSP映像の例として「C10PRO/network three-body image」が記載されている。これはネットワーク型3-in-1カメラを選ぶ根拠だが、国内同梱品の電源仕様やピン配列を確定する根拠にはならない。[A4] **12〜72Vという電圧値はS1-4G資料に載るカメラ仕様なので、納入されるG12用カメラが同一仕様であるとの回答を得るまで電源配線を確定しない。** [A5]

## 接続方針

| 接続先 | この設計での方針 | 確認する点 |
| --- | --- | --- |
| M10 → Pixhawk GPS1 | 付属10-pinケーブルで接続 | 27cmの標準ケーブル長でマスト位置へ届くこと。延長が必要なら重量を追加する |
| GR01 → Pixhawk RC IN・TELEM1 | SBUSをRC IN、UARTをTELEM1へ割当 | 両端のピン配列・信号電圧・TX/RX交差・共通GNDを確認。専用一体コネクターをそのまま挿せるとは仮定しない |
| GR01電源 | 電源基板の12V出力 → GR01のXT30 | GR01公表電流は12Vで300mA。FCのTELEM電源から受信機を給電する構成にしない |
| カメラ映像 | カメラLAN → GR01 LAN | Ethernetの存在だけでPoE給電可能と判断しない。電源線を分ける |
| カメラ電源 | 納入品が12〜72V版であることを確認し、保護された12S主電源分岐へ | 電源基板の12V出力には公差があり、カメラ公称下限12Vを下回り得る。12S満充電50.4Vを許容する納入仕様・ピン配列を確認する |
| TF02-Pro → Pixhawk TELEM3 | UART、信号は3.3V LVTTL、電源は別の5.1V系 | センサー給電を外部から行うときは、TELEM側の電源出力と並列接続しない。GNDは共通化する |
| FRID-1電源 | 5.1V系から給電 | 公表範囲3.5〜8.4V内。12V系には接続しない |

これは配線の役割分担であり、製作に使える確定ピン配列表ではない。電源部品と電流条件は[電源選定](power-selection.md)、取付部品は[機械部品選定](structure-selection.md)を参照する。

TF02-Proの公表電源範囲は5〜12V、平均電流は200mA以下、ピーク300mAである。UART接続はArduPilotにも説明があるが、地面の反射率・草・傾斜などによる測距性能は別途検証する。[A6][A7]

FRID-1は平均18mAで、電源のみで動作する独立装置として搭載する。保護ケースを追加しても、その工作だけで防水性能が成立したとは扱わない。[A8]

ログ用カードはFAT32を基準として机上で認識・連続ログ保存を確認する。カード製品の選定だけでは、組み合わせたFCでの書込み性能を実証したことにはならない。[A11]

## 重量の二重計上を避けるルール

- TF02-Proの50gには80cmケーブルが含まれるので、同じ付属ケーブルを追加配線重量へ再加算しない。
- M10のブザー・安全スイッチ・LEDは内蔵なので別部品を追加しない。32gへの付属ケーブルの包含は未明記のため、含まれない分は電源表の追加配線40gの仮枠で扱い、実測後に重複や不足を補正する。M10 V2など、機能の違う版への代替は別途見直す。
- カメラ150gの設計割当にはカメラの付属ケーブルを含む。追加の機体側電源分岐・コネクターは電源側の配線行、取付ブラケットは機械側の行に計上する。
- GR01の37gにアンテナ・フィーダーが含まれるかは資料で明示されていないため、付属アンテナ・フィーダー一式は別の仮枠で管理する。納入重量を測って包含関係を確定する。
- Pixhawk付属ケーブルセットを全部機体に搭載するとは限らない。実装するSBUS/UART/PWM/電源ケーブルだけを配線行に計上する。ストア内部の発送重量は部品重量に転用しない。
- Pixhawk付属ケーブルの実装分、SBUS/MAVLink、TF02の追加信号線、カメラの機体側電源分岐は、電源資料の追加配線40g仮枠にまとめる。この電装品小計へ再加算しない。
- 送信機、USB接続ケーブル、充電器、SD変換アダプターは地上側であり、離陸重量に加えない。
