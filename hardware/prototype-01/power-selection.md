# 第１弾（B〜D）の電源・配線部品の選定

調査日：2026-11-16。第１弾はM10 GPS、FPVカメラ、TF02-Proを使う初号機で、散布装置・RTKは含めない。このページは部品選定と重量見積りの根拠を記録する。配線図・製作寸法・保護協調を確定した製作指示書ではない。

## 採用する構成

**電源分配と補機用DC-DCはMATEKSYS FCHUB-12S V2を1枚採用する。** 既定のPM08-CANはFC給電と電圧・電流測定に残す。FCHUBのアナログ電流測定出力は使わない。

| 部品 | 選定・数量 | 重量への計上 | 選定理由・残る条件 |
| --- | --- | ---: | --- |
| 主電流測定・FC給電 | Holybro PM08-CAN、**Tinned Wires版** ×1 | 185g、公表値。機体本表で計上 | 12S満充電50.4Vは入力範囲内。8AWG付属線を使い、主経路へXT90変換を追加しない |
| 電源分配・補機用降圧 | **MATEKSYS FCHUB-12S V2** ×1 | **21g、公表値** | 8〜60V入力、4系統のESC電源、5V・12V出力を1枚で確保。絶縁・固定・実装後の放熱を確認 |
| 追加主電源線 | **TQ Wire #802、8AWG赤黒各1ftのセット ×2** | 下の120g仮枠に含む | 高柔軟シリコーン線、外径6mm。搭載長は合計約0.6mを仮置き。余りの購入線は非搭載 |
| 電池にかみ合う機体側端子 | **AMASS AS150系の赤接点 ×2、XT150系の黒接点 ×2** | 下の120g仮枠に含む | 電池2本の相手側4接点。現物の接点形状・雌雄・極性を照合してM/F枝番を確定。端子名の「150」を連続150Aと解釈しない |
| 追加補機電源線 | **TQ Wire #2031、20AWG・3ft巻**。必要数はルート決定後 | 下の40g仮枠に含む | 低電流系に使用。赤黒識別を施す。必要な耐電圧・端末仕様を製作図へ転記 |
| GR01電源の着脱部 | **AMASS XT30U、受信機付属リードに適合する相手側** ×1 | 下の40g仮枠に含む | GR01のXT30電源入力用。5V版の別受信機にはこの12Vリードを使用しない |
| RC・MAVLink・補機信号線 | Pixhawk 6C用ケーブルセットから必要なリードを使用 | 下の40g仮枠に含む | 端子が同じでもピン配置は個別照合。付属線と重複購入・重複計上しない |
| カメラ主電源分岐のヒューズ | **SCHURTER SHT 6.3×32、8020.5014** ×1 | 公表2.84g、下の20g仮枠の内数 | 遅延2A、400VDC。カメラの定常・突入電流と保護協調を確認する条件付き選定 |
| 同ヒューズのホルダー | **SCHURTER FEU Grip、0031.1804** ×1 | 下の20g仮枠に含む | 6.3×32用キャップ込み、600VAC/DC。取付・端子絶縁を含めて実測する |

FCHUBの公表値は基板21gとして扱い、追加配線・はんだ・固定材を含む完成重量とはしない。寸法55×50×6mm、固定穴間隔30.5×30.5mm・穴径3mm。メーカー資料は[製品ページ](https://www.mateksys.com/?portfolio=fchub-12s)と[公式V2マニュアル](https://www.mateksys.com/downloads/Manual/FCHUB-12S-V2_Manual.pdf)。直接ページ取得が不安定な時間帯があり、同一公式URLの検索インデックス本文でも仕様を照合した。V1の数値をV2へ混ぜていない。

PM08の数値は[Holybro製品ページ](https://holybro.com/collections/power-modules-pdbs/products/dronecan-pm08-power-module-14s-200a)を採用。比較表に5.2V表記もあるが、今回の製品ページは各ポート5.3V/3A、入力7〜60.9Vと記載している。PM08専用の適合ケーブルを使い、別の5V出力と並列接続しない。

TQの型番・構造はメーカーの[#802](https://tqwire.com/shop/rc-products/wire/8-gauge/tq-8-gauge-wire-kit-1-black-1-red/)と[#2031](https://tqwire.com/shop/rc-products/wire/18-20-22-gauge/tq-20-gauge-wire/)による。メーカーのこれらのページにはg/m、連続許容電流、絶縁耐圧が揃っていないため、長さとAWGだけで完成ハーネスの電気定格を保証しない。

## 給電先

```text
6S電池2本を直列（12S、満充電50.4V）
  → 電池接続・主ハーネス → PM08-CAN → FCHUB-12S V2
                               ├→ PM08専用出力 → Pixhawk 6C → M10
                               └→ PM08下流主電源 → 選定ヒューズ → カメラ電源候補

FCHUBの未降圧出力 → X6 Plus G2 ×4
FCHUBの12V出力    → GR01受信機
FCHUBの5V出力     → TF02-Pro、FRID-1
```

この図は給電系統のみを示す。RC入力・MAVLink・CAN・カメラEthernetの信号線は省略している。PM08下流のカメラ分岐は独立した小電流回路として設計する。選定した[8020.5014](https://www.schurter.com/en/datasheet/SHT_6.3x32)は400VDC対応で、メーカーの遮断容量は20kA＠63VDC。[0031.1804](https://www.schurter.com/en/datasheet/FEU__Grip_)は6.3×32mm用のホルダーとキャップの組で、600VAC/DC定格がある。50.4Vの回路に32V用の自動車ヒューズ・ホルダーは選ばない。

**2Aという選定値は暫定**であり、カメラ実SKUの定常・突入電流、周囲温度、配線の許容電流、短絡時の予想電流と時間電流特性を照合して確定する。「部品を選んだ」ことを「保護が検証済み」とは扱わない。ホルダーは絶縁した固定面へ取り付け、振動でキャップや接合部が緩まないことも確認する。

| 出力 | 公表されている出力条件 | 接続する負荷との照合 |
| --- | --- | --- |
| PM08 → FC | 5.3V、3A/ポート | FCは専用電源入力へ。M10はFCのGPS1へ |
| FCHUB 5V | 5.1±0.1V、連続5A | TF02-Proは5〜12V、ピーク300mA。FRID-1は3.5〜8.4V、平均18mA |
| FCHUB 12V | 12.0±0.2V、連続4A | GR01の7.2〜72V入力に適合。別のG12 RXは5V仕様なので自動置換しない |
| 主電源分岐 | 12Sパック電圧。50.4Vで評価 | 選定希望のEthernet版3-in-1カメラが実際に12〜72V仕様であることを納入品で照合 |

TF02-Proは下限5Vなので、レギュレーター端子だけでなく負荷作動中のセンサー入力で5V以上あることを確認する。5Vレールの公差下限と配線降下を合わせて下回る場合は、短い適正線径の配線やPM08の独立出力などへ給電設計を変更する。

カメラの公称下限12Vに対し、FCHUBの12V出力は許容差の下限11.8Vとなる。そのため12Vレールで常に動くとは扱わない。Ethernet経由のPoE給電も仮定しない。カメラ・受信機の枝番と重量は機体本表で管理する。

TF02-Proの条件は[Benewake公式データシート](https://en.benewake.com/uploadfiles/2024/04/20240426135509321.pdf)、FRID-1は[双葉公式説明書](https://www.rc.futaba.co.jp/downloads/shop/WCI00000343N2305181557d895t.pdf)で照合した。TF02-Proのケーブル込み50g、FRID-1の9gは機体本表で計上し、ここでは加算しない。

## 電流定格の読み方と未解決の接続条件

[Hobbywing現行仕様書](https://www.hobbywing.com/en/uploads/file/20260104/51c225f38bf68c65072228943ae15f20.pdf)のX6 Plus G2 ESCは、**1基あたり連続25A、ピーク80A（3秒）**。4基の連続定格の単純合計は100Aで、80Aを4倍した320Aを連続運用値にはできない。46V静止推力表の全開電流58Aも、ESCの連続定格と同じ意味ではない。

| 経路 | 公表定格 | この設計での扱い |
| --- | --- | --- |
| FCHUB-12S V2のESCパッド | 1系統70A連続、110Aバースト | 4系統を各ESCへ。接合部と線材の温度・電圧降下は別途確認 |
| PM08-CAN | 200A連続、400Aは25℃で1秒 | 推進4基の100A連続という仕様合計より大きい。ただし4基同時80A×3秒をPM08のバースト定格で保証できない |
| AMASS AS150系 | カタログ75A MAX、8AWG・温度条件付き | 電池側も含め実物の版を照合 |
| AMASS XT150系 | カタログ60A MAX、8AWG・温度条件付き | 主電流が全て通るなら、100A連続を流せる経路としては未成立 |

AS150・XT150は[AMASS公式カタログ](https://www.china-amass.com/public/upload/20240620/94b600a6a4c042646bc89646abc8ea85.pdf)の印刷p30・p25による。定格は測定条件を伴い、その電流を無条件で使用してよいという意味ではない。AS150の耐電圧欄とアンチスパーク性能も分けて扱う。12Sの突入抑制が成立するかは、採用する端子版と総入力容量の確認が必要。

**既存のETop電池端子を維持する選定は条件付きである。** 現物の端子仕様・要求する継続電流・過渡電流が一致することを確認する。成立しない場合は電池側を含むコネクタと主ハーネスを再選定し、変更重量を加える。PDBだけを大電流品にしても、既存端子の制約は解消しない。SITLでの低い平均電流やソフトウェアの電流制限を、端子の定格・物理的な過電流保護の代用にはしない。

カメラ分岐以外の**全主経路には、この調査でヒューズを追加選定していない**。主経路のヒューズの要否・異常時の遮断方式・突入抑制は配線設計で検討し、追加部品が必要なら重量表へ上乗せする。現在の表を、無制限の全開運転が成立する電源設計として扱わない。

## 重量計上

| 項目 | 今回の計上値 | 根拠 |
| --- | ---: | --- |
| FCHUB-12S V2 | 21g | メーカー公表値 |
| 追加主電源ハーネス | **120g（仮）** | 8AWG追加線約0.6m、機体側の4接点、接合・絶縁部材をまとめた設計割当。重量の公表値ではない |
| 追加補機・信号配線 | **40g（仮）** | 補機分岐、XT30相手側、必要なRC/MAVLink等の機上リード。付属線と重複しない |
| カメラ分岐保護 | **20g（仮）** | 8020.5014の2.84g、0031.1804、取付・絶縁部材をまとめた割当。ヒューズ単体を別に足さない |
| **追加する電装の計** | **201g（うち仮定180g）** | 完成実測重量ではない |

120g・40g・20gは、許容上限や必ず収まる見積りを意味しない。ケーブル長・保護部品の最終仕様、製作後の実測で置き換える。実物がない現段階で、非公表部品を0gとして合計することはしない。

次は重複加算しない。

- PM08の185gに含まれる付属主電源線。
- X6 Plus G2の748g/基に含まれるプロペラ・14AWG電源線870mm・信号線。
- TF02-Pro、カメラの本表計上値に含めた付属ケーブル。
- M10の32gに付属ケーブルが含まれるかは未確認。含まれない場合の重量は追加補機・信号配線40gの仮枠で扱い、実測で包含と枠の不足を確認する。同じケーブルを両方へ確定計上しない。
- 地上の充電用変換リード2本、USBケーブル、購入した線材の余り。

## 比較して採用しなかったもの

- **MATEKSYS PDB-HEX**：140A連続、ESCパッド60Aという仕様で、4基用FCHUBの方が配線と電源出力を揃えやすい。[メーカー仕様](https://www.mateksys.com/?portfolio=pdb-hex)
- **MATEKSYS BEC12S-PRO単体**：9〜55V入力・5gで12Sに対応するが、今回のFCHUBと降圧機能が重複するため追加しない。[メーカー仕様](https://www.mateksys.com/?portfolio=bec12s-pro)
- **Pololu D36V50系**：最大入力50Vのため、12S満充電50.4Vの直結用には選ばない。[メーカー仕様](https://www.pololu.com/product/4091)
- **Hobbywing UBEC 10A HV**：3〜14S対応だが、出力は6.0/7.4/8.4Vで今回の5V・12V系をそのまま揃えられない。[メーカー仕様](https://www.hobbywing.com/en/index.php/products/ubec-10a-hv289.html)

この選定によりPDB・DC-DC・追加線材・カメラ分岐保護の部品候補は具体化した。一方、電池端子の電流・突入条件、カメラ実SKUと保護協調、ハーネス製作寸法は、公開資料だけでは閉じられていない。
