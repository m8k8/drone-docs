# 実験002の機体モデルと仮定

このモデルは、購入予定のG06、X6 Plus G2、24×8インチプロペラ、12S 10Ah電池を手がかりにした**暫定の荷重比較モデル**である。実機で校正したG06の再現モデルではない。積載量を増やしたときの基本制御を比較し、次に実測すべき項目を明確にする。

結果は[実験記録](README.md)、再現用設定は[drone-sitl/config/g06](https://github.com/m8k8/drone-sitl/tree/982298a9114657f95e3af62b9ff8eaaa981ba0a8/config/g06)にある。元のExcel、個人のパス、購入情報の全内容はこの実験ディレクトリへ複製していない。

## 1. 反映した計画値

| 項目 | 値 | 根拠と扱い |
| --- | --- | --- |
| 推進系 | X6 Plus G2 ×4、MFP24×8.0 | [Hobbywing公式製品ページ](https://www.hobbywing.com/en/products/x6-plus-g2)の46V静止推力表を近似 |
| 機体の対角寸法 | 1.172m | [EFT公式カタログのG06](https://c.effort-tech.com/yft/service/t9pfu2ax8fcwpyk2bxw2.pdf)のwheelbase。配置は正方形Xで近似 |
| ローター直径 | 0.6096m | 公称24インチの換算値。実際の折り畳みプロペラの外形・有効面積とは区別 |
| 推進ユニット質量 | 0.748kg ×4 | メーカー公表のケーブル・プロペラ込み質量 |
| バッテリー | 12S、10Ah、初期50.4V | 計画の6S 10Ah ×2本直列。容量が減るモデルを有効化 |
| 飛行制御 | ArduCopter 4.7.2、EKF3 | 実機用の制御ソフトをSITLとして実行。Pixhawk 6C基板自体の再現ではない |

G06は実物では矩形構造だが、前後・左右のモーター中心座標を発注SKUの図面で確定できていない。今回は同じ対角寸法の正方形Xを使う。機体中心から各モーターまで0.586m、前後・左右座標の絶対値は約0.4144m。24インチプロペラとの干渉、収納、強度を判定するCADモデルではない。

## 2. 質量条件

空荷質量は次の**仮定**で置いた。

```text
条件付きの公表値部分小計（タンクを別加算）12.4946kg
＋ 型番未確定部品・追加配線・固定具等の仮の割当 1.0000kg
＝ 実験用空荷質量 13.4946kg
```

タンクがフレーム重量に含まれるか、未確認部品が1kgに収まるかは未確定である。13.4946kgは実測値、完成重量の保証、上限・下限のいずれでもない。元計画の空荷11.9kg以下という目標を達成した値として扱わない。

| ケース | 水の追加質量 | 計算に使う総質量 |
| --- | ---: | ---: |
| 空荷 | 0kg | 13.4946kg |
| 水1L | 1kg | 14.4946kg |
| 水3L | 3kg | 16.4946kg |
| 水5L | 5kg | 18.4946kg |

水は1L=1kgとしている。水5Lケースは元計画の満載16.9kg以下という内部目標を超える。シミュレーションで飛行できても、G06の構造上限や搭載可能量の承認にはならない。

## 3. 荷重を増やしてもモーターを強くしない仕組み

標準SITLの`Frame::init`は、JSONの`mass`から推力・消費電力・抗力モデルの係数を初期化する。そのため、`mass`だけを増やすと、モーターの能力も一緒に再計算され、同じ推進系で荷重を比較したことにならない。

この実験では、[固定版ソース](https://github.com/ArduPilot/ardupilot/blob/fb773567896014da007bca58358704d4a0d8516f/libraries/SITL/SIM_Frame.cpp)へ小さな再現可能パッチを適用し、次を分離した。

- `referenceMass = 13.4946`：推進系と抗力係数を決める基準。全ケースで固定。
- `mass`：実際の運動計算に使う総質量。ケースごとに変更。
- `moment_inertia`：機体の回転しにくさ。各ケースで下記の仮定から計算。

基準質量の指定がない標準モデルは、以前と同じ計算を使う。起動ログの`G06 frame mass=... referenceMass=...`を試験プログラムが読み取り、パッチ未適用の実行ファイルやモデル取り違えではアーム前に停止する。

`generate.py --check`は、全ケースのモーターの有効面積、最大流出速度、電力／推力係数が一致することを確認する。荷重増加に合わせて推進能力を増やす操作はしていない。

パッチはArduPilotのGPL-3.0-or-laterコードの変更差分である。元の著作権とライセンスに従い、[ArduPilotのCOPYING](https://github.com/ArduPilot/ardupilot/blob/fb773567896014da007bca58358704d4a0d8516f/COPYING.txt)を参照する。

## 4. 推力・電流モデルの校正範囲

一次資料は[Hobbywingの46V・12S負荷性能表](https://www.hobbywing.com/uploads/file/20251212/be8db6e8539e5b63271859811f66214a.pdf)。メーカー試験条件は海面高度・25℃であり、最大値は1ローターあたり12.526kgf、58.0A。メーカー表とWebページが一致する新しい負荷性能表を採用し、数値の異なる旧マニュアル表は混ぜていない。

標準SITLの簡易式に合わせ、33〜51%の測定点を使って推力曲線を近似した。最大推力を上記の46V値に固定し、`propExpo=0`、有効ゼロ点`spin_min=0.224`となった。このゼロ点は**近似式の係数**であり、実物ESCの不感帯を測定した値ではない。33%未満の領域には今回参照した測定値がない。

| 校正確認 | 最大絶対相対誤差 |
| --- | ---: |
| 推力、測定スロットル33〜51% | 約2.03% |
| 推力、測定スロットル33〜100% | 約8.49% |
| 電流、測定スロットル33〜51% | 約27.64% |
| 電流、測定スロットル33〜100% | 約54.10% |

これは**静止推力表に対する計算上の照合**であり、SITL飛行試験の測定結果ではない。各測定点との比較は[calibration.json](https://github.com/m8k8/drone-sitl/blob/982298a9114657f95e3af62b9ff8eaaa981ba0a8/config/g06/calibration.json)に残す。

標準SITLでは電力が推力に比例するため、実物の非線形な電流曲線全体には一致しない。空荷ホバリング相当の推力で電力係数を合わせている。46V・海面高度で水平ホバリングに必要な推力を仮定した比較は次のとおり。

| 荷重 | メーカー表を補間した4基合計電流 | モデルの4基合計電流 | 差 |
| --- | ---: | ---: | ---: |
| 空荷 | 30.00A | 30.20A | +0.65% |
| 水1L | 33.30A | 32.44A | −2.61% |
| 水3L | 40.84A | 36.91A | −9.61% |
| 水5L | 48.29A | 41.39A | −14.28% |

この表も解析値であり、飛行中の電流ではない。実験は標高584mのCMACで開始し、初期電圧も50.4Vなので、この表と飛行ログの電流が一致することを期待していない。高度による空気密度補正と、電圧の二乗に比例するSITLの推力補正が入る。46V以外の推力曲線はメーカー測定で検証していない。

**容量を10Ahに設定しても、現時点の電流・電池モデルから実機の飛行時間を確定することはできない。** 特に高出力時の電流を過小評価する。

## 5. 公表値がなく、仮定しているもの

| 項目 | 実験の設定 | 限界 |
| --- | --- | --- |
| 電池内部抵抗 | 12Sパック全体で0.06Ω | ETopの実測値ではない。温度・劣化・配線抵抗を個別再現しない |
| 空荷の慣性 | 推進4基を各モーター中心へ、残りを0.50×0.35×0.30mの箱へ配分 | 部品の実配置や脚・アームの質量分布とは異なる |
| 水の慣性 | 半径0.15m・高さ0.22mの円柱を機体重心に固定 | 水面の揺れ、重心の移動、タンク形状、散布による減量はない |
| 重心 | 機体中心、モーター面 | 実際の下吊りタンクや電池の重心ずれは未反映 |
| 抗力 | 基準速度10m/s・傾斜10度、運動量抗力係数0.2 | G06の風洞・飛行測定による校正ではない |
| モーター応答 | スルーレート20/s、標準の簡易ヨー反応 | 実機の時定数・反トルクの同定前 |
| 操縦設定 | 全荷重で同じ設定、通常のアームチェックを保持 | 実機用の調整値として転用しない |
| ホバリング学習 | `MOT_HOVER_LEARN=2` | 各試験を初期状態から始め、飛行中のホバリング出力学習は有効。AutoTuneは実施しない |

水の質量増加に伴う慣性だけは変えるが、重心は固定している。これは静的荷重の比較であり、液体散布中の挙動の再現ではない。

## 6. 今回追加していない機能

通常の仮想GPS・IMU・コンパス・気圧計を使う。RTK補正、M10固有の誤差、TF02-Pro、FPV映像、G12/TWELITEの電波伝搬、Remote ID、ポンプ・ノズル・流量制御、障害物回避は組み込んでいない。風は0m/s。GPS故障や通信断の注入もこの実験の対象外。

重量には完成形の部品群を想定した割当を置いているが、それらすべての機能を模擬した意味ではない。実測重量・部品配置・モーター試験・電池内部抵抗・実機ログが得られたら、モデルを校正し、新しい実験として結果を残す。
