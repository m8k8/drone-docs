# 農業ドローンの設計・シミュレーション資料

実機を購入する前に、ArduPilot SITLで制御を学ぶための手順・検証記録をまとめています。

| 読みたいこと | 資料 |
| --- | --- |
| 環境構築、起動、最初の飛行、終了 | [SITLの実行方法](sitl-execution.md) |
| 地図、姿勢、高度、テレメトリーを見る | [SITLの可視化方法](sitl-visualization.md) |
| 何を試し、どこまで成功したか | [テスト結果（2026-11-16）](sitl-test-results.md) |

## リポジトリの役割

- [drone-docs](https://github.com/m8k8/drone-docs)：この資料リポジトリ。
- [drone-sitl](https://github.com/m8k8/drone-sitl)：セットアップ・起動・自動テストのコード。

手元では同じ親ディレクトリに配置します。

```text
drone/
├── docs/   # drone-docs
└── sitl/   # drone-sitl
```

公開資料の手順と確認状況は2026-11-16時点です。CLIでの基本飛行と自動テストは確認済みです。QGroundControlの可視化は公式手順を調べて記載しており、GUIでの接続・表示は未検証です。

SITLは標準クアッドコプターのシミュレーションを使います。G06の重量、推力、散布装置、5L積載や実機の飛行時間を検証した結果ではありません。

## 更新するとき

実行コードを変更した場合は、使ったコードの版、実行環境、試験条件、実測値、未検証項目をテスト記録へ追記します。失敗した試験を成功した記録で上書きせず、日付別に残します。

このリポジトリはMarkdownの手順書とテスト報告を公開します。手元にある購入計画Excelや結果JSONはGit管理対象外です。依存環境や生の実行ログは、実行コード側のGit管理対象外ディレクトリに保存します。
